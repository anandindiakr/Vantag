Phase 2 — Identify Correct Trademark Classes

Nice Classification — Recommended Classes for Retail Nazar

Critical Decision
India follows the Nice Classification system (12th Edition). Each class requires a separate filing fee. File in the classes most relevant to your current and planned business. The wrong class = no protection in that area.
Class 9

Computer Software & Apps

Software for surveillance, AI detection, video analytics, mobile application for retail security monitoring, downloadable software

PRIMARY — Must File
Class 42

SaaS / Technology Services

Software-as-a-Service (SaaS), cloud computing services, AI and machine learning services, video analytics platform, multi-tenant software services

PRIMARY — Must File
Class 45

Security & Surveillance Services

Retail security monitoring services, theft detection services, loss prevention services, security alert services

PRIMARY — Must File
Class 38

Telecommunications / Alerts

WhatsApp-based alert notification services, real-time messaging services for security alerts, data transmission services

SECONDARY — Recommended
Class 35

Business Intelligence / Analytics

Footfall analytics services, retail business intelligence, customer traffic analysis, business data analysis services for retailers

SECONDARY — Recommended
Class 37

Installation / Maintenance

CCTV installation services, surveillance system setup, camera system configuration, maintenance of security equipment

OPTIONAL — Future Business
Minimum recommendation: File in Class 9 + Class 42 + Class 45 as your core trio. This covers the software product, the SaaS delivery, and the security service. Add Class 38 and Class 35 if budget allows — each additional class costs ₹4,500–₹9,000.

Phase 4 — Filing the Application

TM-A Application Filing

Month 1

Filing Options

Online Filing via ipindia.gov.in (RECOMMENDED)
File Form TM-A online at the IP India e-filing portal. Online filing is faster, cheaper (lower fees), and gives instant acknowledgement with filing date. URL: ipindia.gov.in → e-Services → e-TM → Online Trademark Filing
Recommended₹4,500/class (company) or ₹2,250 (startup)
File in Delhi TM Registry (jurisdiction for Noida)
Noida (UP) falls under the Delhi Trademark Registry jurisdiction. Filing in the correct jurisdiction is required. Principal place of business determines jurisdiction.
Required
File separately for each class
TM-A must be filed separately for each Nice Class. File Class 9, Class 42, and Class 45 as three separate applications. Request multi-class filing (single form, multiple classes) if your attorney recommends it.
Required
Obtain TM Application Number and Filing Receipt
Upon successful filing, you receive an Application Number (e.g., 6001234). Save this — you can use "TM" symbol (™) immediately after filing. The ® symbol is only allowed after registration is granted.
RequiredUse ™ immediately after filing

Immediate Actions After Filing

Update website, app, and all materials with ™ symbol
Add "Retail Nazar™" to your website footer, app store listing, pitch decks, and all marketing materials immediately after filing.
Do Immediately
Track application status at ipindia.gov.in
Monitor your application status every 2–3 weeks. You will receive the Examination Report (typically within 3–6 months) requiring a response.
Ongoing
Respond to Examination Report within 30 days
If the TM examiner raises objections (e.g., similar existing marks, descriptiveness), you must file a counter-statement within 30 days. Missing this deadline abandons your application.
Critical Deadline30-day window

Phase 5 — Post-Registration & Maintenance

After Registration is Granted

Month 12–18 onwards

Registration & Renewal

Update all materials from ™ to ® symbol
Only after receiving registration certificate can you use the ® symbol. Update website, app, letterheads, contracts, and all marketing materials.
After Registration
Set renewal reminder for 10 years (TM-R form)
Indian trademark registration is valid for 10 years from the date of filing, renewable every 10 years. File Form TM-R before expiry. Set calendar reminder 12 months before expiry.
Set Reminder₹9,000 renewal fee (company)
Use the trademark continuously in commerce
A trademark can be challenged for non-use if not used for 5 consecutive years after registration. Maintain records of use (invoices, advertisements, screenshots) as evidence of continuous use.
Ongoing

Monitoring & Enforcement

Monitor TM Journal for similar new filings (every 4 weeks)
Regularly check the Indian Trademark Journal for any new applications similar to "Retail Nazar". You have 4 months to file an opposition after a conflicting mark is published.
Ongoing
Set up Google Alerts for "Retail Nazar" brand monitoring
Create Google Alerts for "Retail Nazar", "RetailNazar", "Retail Nazzar" to catch any unauthorized use of your brand online.

Phase 6 — International Trademark Protection (Future)

Madrid Protocol Filing — When to Go International

Month 18+ / After India Grant
India is a signatory to the Madrid Protocol. Once your Indian trademark is registered (or even after filing), you can file a single international application through WIPO's Madrid System to protect the mark in multiple countries at once.
Priority CountryWhyTiming
UAE / Middle EastEnalytix is eyeing UAE; Indian diaspora retail businesses; large Indian retail communityFile within 6 months of India registration
SingaporeASEAN hub; Indian retail presence; potential SaaS expansionFile within 12 months of India registration
UKIndian retail businesses; Anavid competes hereFile within 18 months of India registration
USAIf Series A funding targeted; protect against US competitorsOnly if US expansion planned — expensive
Recommendation: Focus on India registration first. International filing via Madrid Protocol costs $250–$500 per country designation (WIPO fees) + Indian attorney fees. Do this only after Indian grant and when you have real expansion plans or investor interest in those markets.
